# Передача работы: конструктор иллюстраций (тестовое задание)

## Задание (кратко, из Figma)
Веб-сервис, который собирает композиции иллюстраций из готовых векторных объектов.
- Сценарий 1: человек вводит метафору/заголовок → сервис сам подбирает объекты и собирает композицию.
- Сценарий 2: человек вводит названия объектов → сервис раскладывает их в композицию.
- Ограничение: новые объекты НЕ генерируются, объекты НЕ меняются (только копируются), результат — вектор (SVG).
  AI разрешён для разработки и анализа метафор.
- Что должен уметь: работать с SVG-библиотекой (сохранять структуру, цвета, пропорции); холст — добавлять,
  перемещать, поворачивать, дублировать, удалять объекты, порядок слоёв, сцена из нескольких объектов;
  выбор размера (S/L) и цветовой схемы; загрузка своей палитры и автоматическая перекраска; экспорт в SVG
  с сохранением векторности и редактируемости.
- Правила композиции из макета. Можно: расположение объектов; объект может быть главным (цветной) или фоновым
  (монохром); цвета объекта. Нельзя: менять пропорции объектов относительно друг друга (→ ОДИН общий масштаб
  для всех объектов, без масштабирования отдельного объекта); менять сам объект; нарушать цветовую схему.
- Цвета фона можно использовать в объектах, цвета объектов в фоне — нельзя.
- Сдать: ссылку на работающий сервис или запускаемый проект + короткое демо; репозиторий; краткое описание
  архитектуры (хранение, извлечение, переиспользование SVG); список AI-инструментов; 2–3 примера композиций.
- Оценивают качество и рабочий результат, а не количество функций. Срок — вторник 24.11.

## Что уже сделано
- `tools/figma-export.svg` — экспорт всей библиотеки из Figma (служебный фрейм `_export` в копии макета,
  каждый объект в группе `obj__<id>__<L|S>__<main|bg|fon>`), `tools/figma-export-layout.json` — их координаты.
- `tools/split_figma_export.py` — режет экспорт на объекты: сдвигает в 0,0, убирает служебные id/clip-path,
  заменяет цвета на роли палитры (`fill="@bg1"`). Запуск: `python tools/split_figma_export.py`.
- `data/library.json` и `data/library.js` (`window.IC_LIBRARY = ...`) — библиотека: 10 объектов
  (book, phone, puzzle, coin, headphones, lamp, flowers, wallet, pen, folder) × размеры L/S × main/bg,
  3 декора фона (violet — конфетти+линии, peach — «пол»+линии, teal), палитры. Для L базовый холст 1000, для S — 500.
- `library/<L|S>/<main|bg|decor>/*.svg` — те же объекты отдельными файлами (проверены визуально).
- `data/catalog.json` — названия, алиасы и смысловые теги объектов (для подбора по метафоре).
- `data/palettes.json` — 3 схемы, роли: bg1 bg2 bg3 ink | obj1 obj2 obj3 paper.
- `src/palette.js` — перекраска ролей, сдвиг цветов объекта (colorShift) внутри схемы, разбор пользовательской
  палитры (JSON или 6/8 hex-цветов).
- `src/scene.js` — модель сцены, форматы, рендер в SVG (фон, декор, объекты — каждый в своём `<g id>`), смена S↔L.
- `src/semantic.js` — офлайн-подбор по метафоре (основы слов + теги), разбор списка объектов («лампа, фоновый телефон»).

Архитектурное решение: без сборки и без модулей — обычные `<script src>` с общим `window.IC`,
чтобы `index.html` открывался двойным кликом (file://), на GitHub Pages и как артефакт.

## Что осталось

5. Тесты (`tests/run-tests.js`, node без зависимостей) + проверка в браузере.
6. README (запуск, архитектура, AI-инструменты), 2–3 примера в `examples/`, публикация на GitHub Pages.

## План автокомпоновки (layout.js)
- Вход: главные объекты [{id}], фоновые [{id}], формат W×H, размер L/S, зона под заголовок (null/left/top), seed.
- Доступная область = холст минус зона заголовка (left: правые ~58% ширины, top: нижние ~65% высоты).
- Общий масштаб s: Σ(w·h)·s² ≈ fill·площадь области (fill ≈ 0.45 для 1 объекта, 0.55–0.6 для 3+),
  при этом самый крупный объект не больше ~0.9 области по любой оси. Масштаб общий для всех объектов.
- Случайный поиск (seed, mulberry32) ~500 раскладок + доводка: центры объектов в области, можно выходить
  за край холста до ~20% размера (как в примерах макета), но не в зону заголовка.
  Оценка: штраф за перекрытие (bbox, ужатые на ~12%, порог ~0.15 — лёгкие наложения допустимы, как телефон на книге);
  главный объект виден ≥95%, остальные ≥75%; баланс (центр масс около центра области); разнесённость по области.
- Порядок слоёв как в изометрии: чем ниже нижний край объекта, тем выше слой.
- Фоновые объекты (монохромный вариант, тот же масштаб) — по краям/углам, видно 35–65%, под главными.
- Кнопка «Ещё варианты»: 6 раскладок с разными seed превьюшками, клик — выбрать.

## План интерфейса
- Слева «Сборка»: вкладки «По метафоре» / «По объектам», поле ввода, формат (Квадрат 1000×1000, Обложка 1200×630,
  Пост 1080×1350, Баннер 1920×1080, Сторис 1080×1920), размер S/L, схема, декор фона, «с фоновыми объектами»,
  «место под заголовок», кнопка «Собрать». Под ней — объяснение подбора (какое слово → какой объект).
- Центр: холст (SVG в DOM) + полоса вариантов. Перетаскивание (pointer events, getScreenCTM), рамка выделения
  с ручкой поворота (Shift — шаг 15°), стрелки — сдвиг, Delete, Ctrl+D, Ctrl+Z/Ctrl+Y, [ ] — слои.
  При перетаскивании обновлять только transform перетаскиваемой группы (разметка тяжёлая).
- Справа: библиотека (миниатюры 10 объектов, главный/фоновый, клик — добавить), панель выделенного объекта
  (дублировать, удалить, выше/ниже/наверх/вниз, главный↔фоновый, сменить цвета, поворот), общий масштаб (слайдер),
  палитры (3 из макета + своя: вставить hex/загрузить JSON, хранить в localStorage в try/catch), экспорт
  (SVG, PNG, копировать SVG, сохранить/открыть проект JSON).
- Скачивание: обычный `<a download>`; если открыто как артефакт claude.ai — `await claude.use('downloads')` →
  `downloads.save({filename, data})`; иначе показать «Копировать SVG».
- LLM для метафор (опционально): в артефакте claude.ai — `claude.use('sample')`; локально/на Pages — свой ключ
  Anthropic API (заголовок `anthropic-dangerous-direct-browser-access: true`), модель по умолчанию claude-haiku-5-5.
  Ответ — только id из библиотеки (валидировать), при ошибке — офлайн-словарь.

## Проверки
- Все объекты в композиции — из библиотеки; геометрия (`d` путей) в экспорте совпадает с библиотекой.
- В экспорте нет `<image>`/растра; SVG валиден и открывается в Figma (импорт/перетаскивание) с отдельными слоями.
- У всех объектов один масштаб.
- Сценарий 1: «финансовая грамотность» → кошелёк/монета; «идея для стартапа» → лампа;
  сценарий 2: «лампа, наушники и телефон» → ровно эти три.
